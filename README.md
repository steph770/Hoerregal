# Hörregal

Die NYT-Listen „The 100 Best Books of the 21st Century“ (2024) und „The 50 Best Thrillers of the 21st Century“ (2026) als filterbare Seite: pro Buch ein kurzer deutscher Teaser und das Hörbuch-Angebot auf audible.de, auf Deutsch und auf Englisch.

Seite: https://steph770.github.io/hoerregal/

- Hörbuch-Angaben geprüft auf audible.de, Stand 22. Oktober 2026. Das Angebot ändert sich laufend.
- Cover werden im Browser von [Open Library](https://openlibrary.org) geladen, wo vorhanden.
- Merkliste und „Gehört“ speichert jeder Browser für sich.
